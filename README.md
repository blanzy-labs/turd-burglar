# Turd Burglar

An intentionally crude third-person Godot game. TB-001, **First Flush**, is one
restroom, three toilets, three collectible turds, and one unlocked exit.

## Run

Requires Godot 4.7.2 Standard:

```bash
godot --path .
```

Controls: WASD move, mouse look, E interact, R restart after completion, Esc
release mouse/quit.

Deterministic checks and artifact details are documented in
[`docs/slices/TB-001-first-flush.md`](docs/slices/TB-001-first-flush.md).
